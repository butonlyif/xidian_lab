CHAPTER 10

三模块集成与最终编译

顶层只做例化与连线；ISF 扩到 42 个管脚；看懂最终的四阶段 PASS 与资源报告。

本章目标

把 marquee10、seg_display8、input_ctrl 例化进同一个顶层，补齐全部管脚约束，完成整个教程的最终编译。

STEP 1

集成叙事：连接什么、不连接什么

这一步在做什么：集成不是「把线都连起来」。三个模块的规格边界决定了它们在本迭代的关系—— 共板共存 + 一条最小可视化连线。

  • marquee10 → 10 个 LED（基线资产，端口不动）
  • seg_display8 → 16 个数码管管脚（自由计数显示）
  • input_ctrl → 按键/拨码输入；BUT2 的消抖脉冲直连蜂鸣器（按一下响一拍——纯连线，零新增逻辑）
💬 对 Trae 说：
三个功能都齐了，把它们合到一个工程里编译出最终版本吧，要用的管脚都从板卡资料里查。
可能 · 拨码通道本迭代不接负载

拨码通道 sw_sync_o 本迭代不接负载：综合器会把它优化掉，这是正确行为； 把拨码真正用起来（比如控制跑马灯方向）需要给 marquee10 加端口——那是下一个迭代的新意图，不是集成时顺手改。

知识 · 蜂鸣器为什么零新增逻辑

第 09 章消抖器的输出 btn_pulse 本身就是单周期脉冲，所以 buzzer = btn_pulse[0] 是纯连线：按一下 BUT2（有效按压 >20 ms）蜂鸣器响一拍。 集成阶段不写任何新逻辑，只做例化与连线。

STEP 2

顶层结构（节选）

marquee10      #(.NUM_LEDS(10), .STEP_CYCLES(STEP_CYCLES))  u_marquee      (…led_bus);
seg_display8   #(.TICK_CYCLES(50_000_000), .SCAN_CYCLES(50_000)) u_seg_display8 (…seg_bus, sel_bus);
input_ctrl     #(.NUM_BTNS(3), .NUM_SW(10), .DEBOUNCE_CYCLES(1_000_000)) u_input_ctrl (…btn_pulse, sw_sync);

assign btn_bus = {user_btn4, user_btn3, user_btn2};   // bit0 = BUT2
assign sw_bus  = {dip_sw10, …, dip_sw1};              // bit0 = SW1
assign buzzer  = btn_pulse[0];                         // 按一下，响一拍
看什么三个例化的参数全部沿用各自规格原值，端口名与第 08/09 章规格一致。
知识 · u_input_ctrl 的端口分配原理

btn_bus = {user_btn4, user_btn3, user_btn2}——拼接后 bit0 = BUT2， 所以 btn_pulse[0] 正是 BUT2 的消抖脉冲，buzzer = btn_pulse[0] 即「按 BUT2 响一拍」。

sw_bus 同理：bit0 = SW1，从 SW1 排到 SW10。参数侧 NUM_BTNS(3)、NUM_SW(10)、DEBOUNCE_CYCLES(1_000_000) 全部按第 09 章规格原值例化，仿真里的 DEB=20 只是提速替身。

知识 · 为什么 interface PASS = 重放安全

ISF 必须重放安全：只含幂等的 assign/set，create_* 是一次性 bootstrap、引导后注释着。 每次编译都会把 ISF 完整重放到已持久化的 peri.xml 上—— interface 阶段能 PASS，就是官方对「重放安全」的直接证明。

知识 · 读分层资源报告的三个要点

① 分层报告让你能对每个模块单独问责；② 数码管的 LUT（110）主要花在段码查表与 BCD 进位链； ③ 没有负载的逻辑会被裁剪——「资源变少」有时不是优化好，是连线没接对。

STEP 5

上板预期（连板后逐条勾选）

#预期现象不符时看哪里
110 个 LED 8 Hz 跑马（同第 07 章）第 07 章清单
2数码管显示 00,000,000 起每秒 +1，全帧约 125 Hz 刷新（无闪烁感）不计数 → TICK 分频；闪烁 → SCAN 太慢
3按住 BUT1：LED 全灭且数码管全灭（段全灭、无位选）复位期间输出极性
4快速按一下 BUT2（>20 ms）：蜂鸣器短鸣一声无声 → buzzer 极性/驱动假设
5轻点 BUT2（<20 ms 的抖动）：不响消抖阈值
6数码管「全亮/全暗反转」或「8 变全灭」→ 段极性假设不符DEC-SEG-LOW-ACTIVE：查表取反一处改
