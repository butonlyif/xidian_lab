CHAPTER 01

装好整套环境

从一台空白 Windows 开始，装 Trae、部署 EvoVerse SDK、备好 Icarus Verilog 与 Efinity 工具链。

本章目标

四样东西各就各位：Trae（AI 开发环境）、EvoVerse SDK（本教程的主角）、 Icarus Verilog（仿真器）、Efinity 2026.1（FPGA 原生工具链）。装完在本章末尾能跑三条自检命令。

STEP 1

安装 Trae

这一步在做什么：Trae 是整个流程的驾驶舱——你用自然语言跟它对话，它驱动 SDK 与工具链干活。

从 Trae 官网下载 Windows 安装包，一路默认安装。装完第一次启动时让它完成初始化即可，不需要任何账号之外的配置。

✓ Trae 可启动 · 初始化完成
知识 · 四件套怎么协作

Trae 是驾驶舱：你对它说自然语言，它驱动 EvoVerse SDK 干活；SDK 再分别调用 Icarus Verilog（跑仿真）与 Efinity 2026.1（跑原生编译）。

本教程后面每一章的 💬 话术框，都是说给 Trae 听的。

STEP 2

部署 EvoVerse SDK

这一步在做什么：SDK 提供 VS Code 扩展、CLI、MCP 控制面和板卡目录（catalog），后面每一章都靠它。

拿到 SDK 发布包后解压到一个纯 ASCII 路径（本教程的环境装在 C:\Users\<你>\evoverse-sdk）。然后用随包的部署脚本安装扩展。

# 在 SDK 仓库根目录执行（部署脚本会装好三个扩展）
powershell -File scripts\deploy.ps1
看什么部署完成后，这些位置会出现 SDK 的东西：~\.trae-cn\ 下的扩展目录、 evoverse-sdk\catalog\boards\（板卡资料仓库）、evoverse-sdk\runtime\（控制面引擎）。
✓ deploy.ps1 一次装好三个扩展
知识 · 为什么必须纯 ASCII 路径

Efinity 对中文路径敏感——SDK 安装路径（以及后面所有工程路径）都必须保持纯 ASCII， 本教程统一装在 C:\Users\<你>\evoverse-sdk。

STEP 3

安装 Icarus Verilog（仿真器）

这一步在做什么：控制面的 verification.simulate 用 iverilog 跑阻塞仿真，是每个候选晋级的门槛。

# 用 winget 一条命令装好，装完重开终端
winget install SteffanIcarusVerilog.IcarusVerilog
iverilog -V
vvp -V
看什么两条版本命令（iverilog -V / vvp -V）都能打印版本行。
✓ iverilog / vvp 版本行都能打印
状态 · 版本基线

本教程实测 iverilog 12 系列。

修复 · 提示找不到命令

多半是 PATH 没刷新——重开一个终端就好。

STEP 4

安装 Efinity 2026.1

这一步在做什么：原生编译（综合、布局布线、生成比特流）全靠它；Trion T20F256 是它的目标器件。

用 Efinix 官网下载的安装器装到 C:\Efinity\2026.1（默认路径即可，同样保持纯 ASCII）。 装完先不急着打开 GUI——本教程全程用命令行驱动它。

✓ C:\Efinity\2026.1 就位 · 全程命令行驱动
修复 · 提前打个预防针

直接双击 efx_run.bat 会因为缺 PYTHONHOME 等环境变量而报：

ModuleNotFoundError: No module named 'encodings'

第 06 章会给出完整的命令行环境封装，这里不用处理。

STEP 5

获取 Catalog（板卡资料库）

这一步在做什么：Catalog 是 SDK 的版本化物料库——器件管脚权威库、板卡管脚表、骨架工程模板都在里面。 它不随 SDK 安装预置，要单独获取。本教程的 t20f256-xd-ps-eval 就住在官方 Catalog 的 stable 频道里。

方式 A：在线 sync（推荐）

SDK 自带一条公开的 Catalog 发布通道，不需要 GitHub 账号。在任意目录执行：

& "C:\Users\<你>\evoverse-sdk\evoverse.cmd" sync

✓ catalog synced（stable 频道）
# 可选参数：--channel preview（尝鲜频道） / --json（机器可读输出）
# 私有/镜像仓库可用 --repository URL 或环境变量 EVOVERSE_CATALOG_REPOSITORY 覆盖

方式 B：离线包（没有外网时）

按你拿到的包形态二选一：

  • 散件资料包（zip 里是 pdf/csv/isf/md 等板卡资料散文件）——用导入命令：
& "C:\Users\<你>\evoverse-sdk\evoverse.cmd" import-local D:\downloads\t20f256-board-materials.zip

→ importing into C:\Users\<你>\evoverse-sdk\catalog\boards\t20f256-board-materials
  imported files:  · 2 → docs/  · 1 → pinout/  · 3 → constraints/  · 1 → root/
✓ board imported as t20f256-board-materials
  • 已成型板卡目录（官方发的完整板卡文件夹，内部已是 board.yaml + pinout\ + jackets\ + … 的 Catalog 结构）——不要走 import-local，直接整个文件夹放进 SDK 的板卡目录：
# 目标位置：<SDK 安装目录>\catalog\boards\，目录名就是板卡 id
Expand-Archive D:\downloads\t20f256-xd-ps-eval.zip -DestinationPath "C:\Users\<你>\evoverse-sdk\catalog\boards\"

# 放好后 SDK 通过目录枚举自动发现它（下一节验证）
✓ catalog synced（stable 频道）· 本板卡随包就位
可能 · 方式怎么选

方式 A 在线 sync（推荐）：SDK 自带公开发布通道，不需要 GitHub 账号，一条命令拿到整个 stable 频道。

方式 B 离线包：没有外网时用；按包形态二选一——散件资料包走 import-local 导入， 已成型板卡目录直接放置。

状态 · sync 之后发生了什么

物料装进 <SDK>\catalog\（boards/devices/ips）；同时在 <SDK>\.cache\catalog.git\ 留一个源仓库、写一份 catalog-sync-receipt.json 回执 （含版本号、commit、treeDigest——内容指纹，任何篡改会让下次 sync 失败）。

旧版本会自动备份到 catalog.previous\。

本教程实测：sync 到 stable 0.9.6，本板卡随包就位。

可能 · 不爱命令行

命令面板里的 EvoVerse: Sync Catalog 和 Welcome 页上的同步按钮是同一件事。

知识 · import-local 的能力边界

散件导入时 SDK 会自动按类型归类，并推导板卡 id（可用 --id 指定，同名已存在加 --force）。

import-local 也接受文件夹 / .tar.gz / 单个 .md / 单个 .pdf——数据手册也能起步， SDK 会建板卡目录并把 PDF 归入 docs/ 等待元数据提取。

修复 · 成型目录别走 import-local

import-local 走的是散件路由，会把 jackets 结构打散——已成型板卡目录不要导入， 直接整个文件夹放进 <SDK>\catalog\boards\（目录名就是板卡 id）。

STEP 6

确认整个环境就位

这一步在做什么：三条命令做最终体检，全绿才进入第 02 章。

& "C:\Users\<你>\evoverse-sdk\evoverse.cmd" catalog status

# ② 板卡清单里能看到本教程板卡（版本 1.0.0）：
& "C:\Users\<你>\evoverse-sdk\evoverse.cmd" list boards

# ③ 仿真器与 FPGA 工具链：
iverilog -V
Test-Path C:\Efinity\2026.1\bin\efx_run.bat
True
看什么① Catalog: ready；② 清单里 ● t20f256-xd-ps-eval 1.0.0；③ True。
✓ 三条全绿 · 环境就位
修复 · 三种不顺

① 报 not-ready / 没有回执：还没执行过 sync（或 sync 中断）——回到 STEP 5 方式 A 重跑。

② 板卡不在列：要么 sync 的频道/版本不含它（用 catalog status 看 catalog_version， 本教程要求 ≥0.9.6），要么离线放置的目录名/位置不对——确认文件夹在 <SDK>\catalog\boards\<板卡id>\ 且里面有 <板卡id>.md。

② 显示 ? 加告警：某些板卡元数据不全属正常（不影响本板卡）， 只认 t20f256-xd-ps-eval 那一行是 1.0.0 即可。

状态 · 就位后的文件

<SDK>\catalog\boards\t20f256-xd-ps-eval\（板卡文档、 pinout\t20f256-xd-ps-eval.csv 110 行管脚表、jackets\stage0\ 骨架模板）、 <SDK>\catalog-sync-receipt.json（sync 回执）。
