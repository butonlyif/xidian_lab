## EvoVerse project review

Before reporting that the project reached a milestone, paused, or completed,
you MUST inspect `project-review/` and use the `evoverse-project-review` skill
to create or update the matching `project-review/<case-id>/review.md`. If the
review is missing or cannot be updated, report `REVIEW_REQUIRED` and must not report the task as complete.
Keep observations, user reports, and hypotheses separate. Preserve only selected
evidence and never upload project material automatically.
